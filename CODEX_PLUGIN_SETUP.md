# Подключение Svetikony к Codex — результат

10 сентября 2026.

Плагин `svetikony@personal` создан, установлен и включён в Codex. Проверена именно установленная конфигурация MCP: 18 инструментов доступны, административный API подключён.

- Исходники: `integrations/svetikony/`.
- Личная копия: `/Users/dmitrijfomin/plugins/svetikony`.
- Marketplace: `/Users/dmitrijfomin/.agents/plugins/marketplace.json`.
- Установленная версия: `0.1.0`.
- Среда: **локальная**, `http://localhost:3000`.
- Production: **не подключён** — существующий локальный сервисный ключ получил HTTP 401 от production administrative API. Ключи не выводились и не копировались в плагин.

## Что работает

Чтение 7 редакционных разделов, поиск записей, входящие/исходящие связи, аудит полей и SEO, покрытие 365/366 дней, локальные предложения изменений, запись черновика, отдельная публикация, проверка сохранения, журнал операций, подготовка обратной редакции, контекст изображения для даты и загрузка изображения с предложением привязки.

Предложения до применения хранятся локально, а не в админке. Прямую генерацию изображений выполняет доступный инструмент Codex; плагин сам модель изображений не вызывает. Он также не запускает фонового ИИ после закрытия Codex. Схема годовых источников и many-to-many связей из большого плана ещё не реализована.

## Проверки

- 28 тестов плагина прошли, включая настоящий MCP handshake, запрет опасных маршрутов/полей, публикацию отдельной командой, конфликт ручных правок, защиту от повторов, сценарий неопределённого исхода записи и маркировку AI-изображения.
- Автономная сборка плагина выполнена.
- `npm run typecheck` админки прошёл.
- Манифест и skill прошли официальные локальные валидаторы plugin-creator/skill-creator.
- Read-only проверка настоящего API: 30 дней календаря, 27 святых, 0 икон, 60 молитв, 16 статей, 5 чтений, 138 записей азбуки. Все эти числа относятся к локальной D1, а не production.
- Отдельно запущена установленная копия: 18 инструментов, `connected: true`.
- Во время настройки не было записей в CMS, генераций изображений, публикаций, отправок Telegram, commit/push/deploy. Приложение публичного сайта не менялось.

## Начать работу

Откройте новый чат Codex, включите «Світ Ікони · Codex» и выберите GPT-6 Astra, если она доступна. Плагин не меняет выбранную модель клиента. Начальная команда:

> Используй плагин Svetikony. Проверь среду, проанализируй календарь на 2026 год и связи материалов. Подготовь план исправлений без публикации и сообщай о ходе работы.

Локальный сайт должен оставаться запущенным. При отсутствующем подключении плагин сообщает об ошибке, а не подменяет данные.

Для production нужен действующий административный доступ, настроенный локально вне переписки и кода плагина. Не присылайте токены в чат. Переключение среды должно быть явным; предложения разных API-origin изолированы.
