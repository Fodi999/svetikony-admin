# Аудит плана «Візуалізатор»

Дата: 10 сентября 2026. Проверены локальные проекты `svet-ikony` и
`svetikony-admin`. Это проверка существующей реализации, не новое выполнение
инструкций из приложенного плана. Рабочий код во время аудита не изменялся.

**Вывод: план выполнен частично. Основа MVP есть, но считать весь модуль
завершённым и проверенным нельзя.**

«Есть» ниже означает наличие реализации в коде; это не подтверждение
работы каждой функции в production. Полный браузерный сценарий загрузки
настоящего GLB не проверен: доступ к управлению Chrome отсутствует.

## Существенные незакрытые пункты

1. **Предпросмотр GLB в админке: конфликт CSP/CORS.**
   `features/visualizer/visualizer-event-form.tsx:278` передаёт результат
   `lib/media/resolve-preview-url.ts:29` в `ModelViewerPreview`. Это URL сайта,
   а не BFF админки. `next.config.ts:74` задаёт `connect-src 'self'`, поэтому
   при размещении админки и сайта на разных origins production CSP блокирует
   загрузку модели. Публичный `/media/*` сайта также не добавляет CORS-заголовки.
   Нужно организовать совместимую выдачу модели, предпочтительно через
   существующий same-origin BFF, и проверить реальный GLB в браузере.

2. **GLB события не загружается без координат.**
   `svet-ikony/components/site/visualizer/Earth3DCanvas.tsx:267` возвращается
   до загрузки модели, если latitude или longitude отсутствует. Координаты
   по плану nullable: они должны управлять переходом камеры, а не разрешением
   показывать GLB.

3. **Нет плавного приближения к событию и размещения его сцены у точки.**
   В `Earth3DCanvas.tsx:281` сохраняется текущий радиус камеры; строка 307
   использует его без изменения. Меняются поворот Земли и наклон камеры.
   GLB добавляется в `eventGroup` без подгонки масштаба и положения
   (`:328`), поэтому произвольная сцена из Blender может оказаться внутри
   Земли либо вне кадра. Широта камеры учитывается с коэффициентом 0.6,
   выбранная точка не всегда оказывается в центре.

4. **Metadata загрузки не доходит до D1.**
   `components/forms/media-upload-button.tsx:53` оставляет только id/url.
   Форма события (`features/visualizer/visualizer-event-form.tsx:272`) и
   загрузка основной Земли передают только `r2Key`. В результате filename
   и MIME сохраняются пустыми, fileSize — 0, хотя столбцы и API предусмотрены.

5. **Нет проверки общих ссылок перед удалением R2-файла.**
   `svet-ikony/app/api/admin/church-content/visualizer-models/[id]/route.ts:42`
   удаляет запись, затем вызывает `bucket.delete(existing.r2Key)` без
   поиска других ссылок. Другой объект с тем же ключом может потерять модель.
   Удаление события оставляет записи моделей без существующей группы, когда
   удалён последний перевод. Основная Земля при удалении события не удаляется.

6. **Загрузка GLB проверяется не полностью.**
   Лимит 50 MiB и UUID-ключи есть. Расширение `.glb` проверяется только при
   MIME `application/octet-stream`, но не при `model/gltf-binary`.
   Пустой MIME отклоняется, клиент его не нормализует. При принятом
   `application/octet-stream` именно этот MIME сохраняется и отдаётся,
   вместо требуемого `model/gltf-binary`. Содержимое GLB не проверяется.

7. **Хронология реализована с ограничениями.**
   Публичный UI группирует века/годы по числу, без calendarEra, затем
   сортирует возрастающим числом (`HistoryVisualizer.tsx:96–119`). Поэтому
   годы до н. э. идут в обратном историческом порядке, одинаковые годы
   BC/AD могут попасть в одну группу внутри эпохи. Подпись века определяет BC
   по знаку century, тогда как API отдельно хранит calendarEra. Год окончания
   не используется в автоматически сформированной подписи периода.
   Для неизвестной даты нужно проходить «неизвестный век → неизвестный год».
   `sortYear` есть в D1/API, но исключён из административного BFF/формы:
   вручную упорядочить события без точных дат из админки нельзя.

8. **Предпросмотр и управление моделями в админке неполные.**
   Основная Земля имеет upload/replace, но не встроенный preview и не
   отдельную кнопку удаления. Модели события имеют upload/delete/preview;
   отдельной замены существующей записи нет. Общий preview события показывает
   только название и summary. `ModelViewerPreview` имеет play/pause/reset и
   имена анимаций, но не обрабатывает ошибку загрузки: spinner может зависнуть.
   Текст «візуалізатор не працюватиме без неї» в карточке Земли устарел после
   добавления резервного глобуса.

## Выполненные проверки

- Сайт, предшествующий шаг этой сессии: 87 файлов, **910 тестов passed**;
  `npm run typecheck` passed; 16 параллельных HTTP-запросов страниц/API — 200,
  без SQLITE_BUSY/ERR_RUNTIME_FAILURE в ответах. Код после этого не менялся.
- Админка, текущий аудит: 75 файлов, **522 теста passed**;
  `npm run typecheck` passed; `npm run lint`: 0 errors, 25 warnings.
- Сайт, текущий аудит: `npm run lint` не работает — script вызывает
  `next lint`, Next трактует `lint` как несуществующую директорию проекта.
- В каталоге e2e админки нет сценария визуализатора. Текущие успешные тесты
  не подтверждают реальную загрузку GLB через админку и его показ посетителю.
- Полные production builds обоих проектов в этом аудите не запускались;
  актуальный результат сборок не подтверждён.
- Локальная база при проверке в этой сессии содержит 0 событий и 0 моделей.
  Контент не создавался автоматически: это соответствует запрету из плана.
- Production D1/R2, deployment и визуальное отображение не проверены.
